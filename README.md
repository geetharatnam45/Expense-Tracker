### Real-Time Chat Application

The **Real-Time Chat Application** is a web-based communication platform that allows users to exchange messages instantly over the internet. The application provides a simple and interactive interface where users can register, log in, search for other users, and send and receive messages in real time.

The application is developed using **React.js** for the frontend and **Spring Boot** for the backend. **REST APIs** are used for user authentication and data management, while **WebSocket technology** can be used to enable real-time message delivery without requiring the user to refresh the page. **MySQL** is used to store user information, chat messages, and conversation details.

### Key Features

* User registration and login
* Secure user authentication
* One-to-one real-time messaging
* Online/offline user status
* Chat history
* User search
* Message timestamps
* Responsive and user-friendly interface
* Real-time message notifications
* Persistent storage of conversations

### Technologies Used

**Frontend:** HTML, CSS, JavaScript, React.js, Axios
**Backend:** Java, Spring Boot, REST API, WebSocket
**Database:** MySQL
**Tools:** Eclipse/STS, VS Code, Postman, Git/GitHub

### Project Objective

The main objective of this project is to develop a fast, reliable, and user-friendly communication system that enables users to exchange messages in real time. The project also demonstrates practical knowledge of **React.js, Spring Boot, REST APIs, WebSocket communication, database integration, and full-stack web development**.
